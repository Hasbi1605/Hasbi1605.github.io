# Proposal: Fix 404 Error on Project Detail Pages

**Goal:** Memperbaiki halaman detail project "ISTA AI" dan "ISTURA App" agar tidak 404 saat dibuka.

---

### Analisis Masalah:
*   *Akar Masalah:* Next.js static export menggunakan fungsi `generateStaticParams()` di `src/app/work/[slug]/page.tsx` untuk menentukan semua halaman detail proyek yang harus di-build saat compile.
*   Dua proyek baru (`ista-ai` dan `istura-app`) telah ditambahkan ke `work-data.json`, tetapi slug mereka **belum didaftarkan** di `generateStaticParams()`. Akibatnya, file static HTML untuk kedua halaman tersebut tidak terbuat dan memicu error `404` saat diakses.

---

### Perubahan Kode yang Diusulkan:

Pada `src/app/work/[slug]/page.tsx`:

*   *Sebelum:*
    ```typescript
    export function generateStaticParams() {
      return [{ slug: "barbershop-pos-system" }, { slug: "minibox-barbershop" }, { slug: "core-initiative-frontend" }, { slug: "schizocheck-expert-system" }, { slug: "dewamotor-inventory-catalog" }, { slug: "fti-umby-website-remake" }];
    }
    ```
*   *Sesudah:*
    ```typescript
    export function generateStaticParams() {
      return [
        { slug: "istura-app" },
        { slug: "ista-ai" },
        { slug: "barbershop-pos-system" },
        { slug: "minibox-barbershop" },
        { slug: "core-initiative-frontend" },
        { slug: "schizocheck-expert-system" },
        { slug: "dewamotor-inventory-catalog" },
        { slug: "fti-umby-website-remake" }
      ];
    }
    ```
